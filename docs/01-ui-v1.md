# UI v1 brief

The first milestone was a UI prototype: a simple entry screen and an in-match screen with basic interaction.

The match screen:

- Follows the standard ruleset
- Portrait
- Uses fake data with no logic behind it
- Layout, top to bottom:
  - The victory rule and progress towards it; the standard rule is a single score, shown like `07/15`
  - The opponent's name and card counts, paged left and right in a loop (up to 6 opponents)
  - The gem bank, showing how many gems are still available
  - The noble panel, up to 5 nobles
  - The card market
  - The player's own area, showing the number and type of cards held
- Rectangles represent permanent gems (cards), circles represent gem tokens, and squares represent nobles
